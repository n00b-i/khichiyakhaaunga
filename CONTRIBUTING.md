# Contributing Guidelines

## Branching Strategy (Solo Dev)
To prevent merge conflicts and overhead, **we do not use feature branches**. 
*   All code is committed directly to the `main` branch.
*   Always `git pull` before starting a session.
*   Commit early, commit often.

## Commit Message Format
*   `feat: added product clash engine`
*   `fix: resolved touch lag in umbra`
*   `docs: updated roadmap`
*   `chore: updated dependencies`
