# Lucide Icons Reference (Verified)

This file contains verified icon names from the `flutter_lucide` package. Use these exact names in `LucideIcons.<name>`.

- `layout_dashboard` (Dashboard)

## How to Find More Icons
1. Visit the official `flutter_lucide` [ICONS.md](https://github.com/ravikovind/flutter_lucide/blob/main/ICONS.md).
2. Use `Ctrl+F` / `Cmd+F` to search for the icon name.
3. Replace `-` with `_` in the name (e.g., `pin-x` → `LucideIcons.pin_x`).
