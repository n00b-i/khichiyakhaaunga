# Project Context: comeback.in

## Core Philosophy
1. **UI/UX > Logic:** The visual feedback, haptics, and animations are the product. The math logic is just the engine underneath.
2. **No Friction:** Never lock the user out. If they make a mistake, penalize their score, but keep the game loop running. The system runs; the user's brain freezes.
3. **Never Give the Answer:** In visual puzzles (like Rebus), never write the solution text in the UI. Use Flutter Canvas, geometry, and typography to imply the answer.

## The Games
1. **Number Hunt:** Find the smallest number among drifting orbs.
2. **Product Clash:** Tap two numbers that multiply to the target.
3. **Rebus:** Pure visual word puzzles using typography and positioning.
4. **Umbra:** A memory/flashlight game where you must memorize grid positions in the dark.
